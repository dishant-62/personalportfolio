# Dishant Rathi — Personal portfolio

A single-page Next.js, React and TypeScript portfolio with an editorial visual system and responsive layouts.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Personalize before publishing

Update `lib/content.ts` with your public email, LinkedIn and GitHub profile URLs, confirmed skill inventory and resume path. Keep a PDF resume in `public/` and set its path there.

Project copy is deliberately scaffolded: fill each `[ADD …]` prompt with the verified problem, solution, architecture, your role and outcome. Keep stages accurate as the ideas progress. Add project URLs only after a working public demo or repository exists. Add a real GSK contribution under experience after confirming details you can share publicly.

## Deploy

Deploy to Vercel or another Next.js host. The page uses no stock imagery or animation package. Google Fonts are requested by CSS; system font fallbacks remain available if the font service cannot load.
